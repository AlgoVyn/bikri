Install

Windows: unzip, then run in PowerShell:

powershell -ExecutionPolicy Bypass -File .\install.ps1

Linux or macOS: extract the archive and run ./install.sh.

Then open Bikri → Settings → Printer → Set up printer → Print service, copy the pairing code from http://127.0.0.1:17890/ and choose your printer.

Unsigned build: Windows SmartScreen (or macOS Gatekeeper) may warn the first time. Verify the archive against SHA256SUMS and only download from the official Algovyn/Bikri release page. Do not disable security warnings globally.

What it does

  • POS mode sends ESC/POS through the installed print queue, keeping the cash drawer, cutter and QR code working.
  • Compatibility mode prints a rendered receipt image through the printer driver for non-ESC/POS printers.
  • The agent listens only on this computer (127.0.0.1:17890), pairs with a one-time code, and never sends shop data to Algovyn.
